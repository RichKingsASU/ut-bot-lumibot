# Doppler + GitHub Actions Setup

1. Go to [doppler.com/integrations/github-actions](https://doppler.com/integrations/github-actions)
2. Connect the `disrupting-alpha` project
3. Select the `production` environment
4. Select repo: `RichKingsASU/ut-bot-lumibot`
5. Enable sync
6. The secrets will automatically appear in your GitHub repo under:
   **Settings** → **Secrets and variables** → **Actions**
